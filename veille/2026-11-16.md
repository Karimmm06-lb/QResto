# Veille techno — 2026-11-16

## Ce qui change pour toi
- **Supabase CLI v3.0.0** (2 nov) — nouvelle version majeure, installée par défaut via npm/Homebrew/Scoop/Linux/`supabase/setup-cli` ; binaire unique `supabase`, `supabase-go` n'est plus installé → QResto : si tes scripts/CI de migrations appellent `supabase-go` ou épinglent l'ancienne version, vérifier avant le prochain `npm i`/déploiement.
- **Supabase TLS** (10 nov) — certains chiffrements TLS 1.2 désactivés sur les API HTTP des projets (impact <0,0001 % du trafic) → QResto : négligeable pour navigateurs modernes ; à garder en tête si un vieux terminal/tablette de restaurant (Android ancien) échoue à se connecter.
- **Next.js security release** (3 nov, 7 avis dont fuite de cache cross-tenant ; correctifs 16.4.5 / 15.5.29, 16.4.6 en latest selon source tierce non officielle) → si un projet React/Next est sur Vercel, passer à la dernière 16.4.x / 15.5.x ; vérifier les avis officiels sur nextjs.org.
- **Node.js (rappel)** — patch du 11 nov (22.23.5 / 24.22.3 / 26.13.1, sévérité max HIGH) toujours à appliquer sur El Falek ; se référer à l'avis officiel nodejs.org pour les CVE (IDs divergents selon les sources).
