# Veille techno — 2026-11-10

## Ce qui change pour toi
- **Supabase — coupure de chiffrements TLS 1.2 (aujourd'hui, 10/11)** — un sous-ensemble de ciphers TLS 1.2 est désactivé sur les API HTTP des projets (<0,0001 % du trafic) → QResto (Vanilla JS dans navigateurs récents) n'est normalement pas touché ; vérifier qu'aucun vieux client/borne/tablette de restaurant ancienne n'échoue.
- **Supabase CLI v3.0.0 (02/11)** — npm, Scoop, paquets Linux et `supabase/setup-cli` installent désormais v3 par défaut (Homebrew depuis le 03/11) → si tes scripts/CI de migrations QResto utilisent `setup-cli` ou `npx supabase`, tester en v3 ; sinon épingler v2 via le canal v2.stable (v2.122.1).
- **Supabase — adaptateurs @supabase/server Hono/H3/Elysia/NestJS dépréciés, suppression le 01/12** → aucun impact sur QResto (client JS direct) ; à vérifier seulement si El Falek utilise ces adaptateurs.
- **Node.js — release sécurité annoncée le 11/11 (lignes 22, 24, 26, sévérité max HIGH)** → prévoir la mise à jour de Node pour El Falek (Express/Prisma) dès demain, y compris l'image/runtime sur le déploiement.
- **Next.js — release sécurité du 03/11 (7 vulnérabilités medium)** ; 16.4 sortie le 06/10 → aucun projet Next actuel, mais à appliquer si tu migres un projet vers Next/Vercel.

## À surveiller

- Marché QR ordering : aucune actu datée de la semaine trouvée (recherche peu concluante).
