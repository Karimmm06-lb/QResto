# Veille techno — 2026-11-09

## Ce qui change pour toi
- **Supabase CLI v3.0.0 (2 nov.)** — npm, Scoop, paquets Linux et `supabase/setup-cli` passent par défaut en v3 (Homebrew le 3 nov.), un canal v2.stable existe → QResto : si tes migrations/CI utilisent `setup-cli` ou `npx supabase` sans version fixée, épingle la v2 ou teste la v3 avant le prochain déploiement.
- **Supabase TLS (demain, 10 nov.)** — Désactivation d'une partie des chiffres TLS 1.2 sur les APIs HTTP des projets (<0,0001 % du trafic) → QResto : vérifie vite qu'une vieille tablette/WebView Android client charge encore le menu.
- **Next.js (release sécurité du 3 nov.)** — 7 vulnérabilités de sévérité moyenne corrigées ; Next 16.4 (6 oct.) est la ligne actuelle → seulement si tu utilises Next.js sur un projet (aucun des 3 actuels ne semble en dépendre) : sinon rien à faire.
- **Node.js (rappel)** — Release sécurité des lignes 22/24/26 confirmée pour le **11 nov.**, sévérité max HIGH → El Falek : planifie la mise à jour Node juste après publication.

## À surveiller
- Advisory Node : nodejs.org/en/blog/vulnerability/november-2026-security-releases (CVE à lire dès le 11 nov.).
- Supabase : retrait des adaptateurs Hono/H3/Elysia/NestJS de `@supabase/server` le 1er déc. (concerne uniquement si tu les utilises).

## Action immédiate
- Avant le 10 nov. : épingler la version du CLI Supabase dans la CI/scripts de QResto si elle est flottante.
