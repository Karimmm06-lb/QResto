# Veille techno — 2026-11-14

## Ce qui change pour toi
- **Node.js (avis confirmé, 11 nov)** — versions corrigées **22.23.5 / 24.22.3 / 26.13.1** ; 16 CVE dont **7 High** (CVE-2026-123863/64/65/66, 126051, 123872, 123874) : HTTP/2 (use-after-free, abort distant, fuites mémoire/FD), fuite de heap en HTTPS (llhttp), contournement d'auth client TLS 1.2 (renégociation de servername) → El Falek (Express) : mettre à jour Node dès aujourd'hui, surtout si le serveur est exposé en HTTPS/HTTP2 direct ; derrière Vercel/reverse proxy, l'exposition est réduite mais le patch reste recommandé.
- **Node.js medium** — CVE-2026-123871 (identifiants proxy dans les messages d'erreur) et CVE-2026-123877 (réutilisation de session TLS dans `https.Agent`) → vérifier si El Falek utilise un proxy sortant ou `https.Agent` personnalisé ; mettre à jour règle ces deux cas.
- **Supabase CLI v3.0.0** (par défaut depuis le 2-3 nov) → QResto : si migrations/CI utilisent `supabase/setup-cli`, vérifier le pipeline ou épingler la v2.
- **Supabase TLS** (désactivation d'anciens chiffrements TLS 1.2 sur les API HTTP depuis le 10 nov) → sans impact pour un navigateur moderne ; à tester pour d'éventuels anciens clients/scripts appelant QResto.

## À surveiller
- `@supabase/server` : adapters Hono, H3, Elysia, NestJS supprimés le 1er décembre 2026.
- Next.js : release de sécurité du 3 nov (7 advisories medium, dont fuite de cache cross-tenant selon une source tierce non vérifiée) → à appliquer seulement si un projet utilise Next.js.

## Action immédiate
- Mettre à jour Node.js d'El Falek (et de l'environnement de dev/CI) vers 22.23.5, 24.22.3 ou 26.13.1 selon la ligne utilisée. Les lignes EOL (ex. Node 20) sont aussi affectées et non corrigées → migrer vers 22 LTS ou plus récent.
