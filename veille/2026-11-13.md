# Veille techno — 2026-11-13

## Ce qui change pour toi
- **Supabase CLI v3.0.0** (2-3 nov) — devient la version par défaut (npm, Scoop, Linux, `supabase/setup-cli`) → si tu utilises le CLI pour QResto (migrations, CI), vérifie que rien ne casse ou épingle la v2.
- **Supabase TLS** (à partir du 10 nov) — suppression des anciennes configs TLS sur les API HTTP des projets → impact négligeable pour un navigateur moderne, mais à vérifier pour d'éventuels scripts/clients anciens appelant l'API QResto.
- **Node.js** — release de sécurité annoncée pour les lignes 22/24/26 autour du 11 nov (sévérité max HIGH, CVE pas encore confirmés dans mes sources) → à appliquer sur El Falek (Express/Prisma) dès confirmation sur nodejs.org ; Node 20 et antérieurs ne seront pas corrigés.
- **Next.js** — release de sécurité du 3 nov (7 vulnérabilités medium) ; dernière feature release 16.4 (6 oct) → si un projet utilise Next.js/Vercel, mettre à jour vers la dernière patch.

## À surveiller
- `@supabase/server` : adapters Hono, H3, Elysia, NestJS supprimés le 1er décembre 2026.
- QR ordering : MENU TIGER couple QR ordering et POS cloud ; Hostie ajoute la commande à emporter sans commission → tendance à l'intégration POS/takeout, piste d'évolution pour QResto.

## Action immédiate
- Consulter l'avis Node.js de novembre (nodejs.org/en/blog/vulnerability/november-2026-security-releases) et mettre à jour El Falek si une version corrigée est publiée (sévérité HIGH).
